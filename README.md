# SnowPro Certification Quiz App

A browser-based quiz app for SnowPro certification preparation. Zero dependencies — runs locally in any modern browser.

## Quick Start

1. Download `snowpro-quiz-app.zip` from this repo
2. Unzip the file
3. Open `app/index.html` in your browser

That's it — no server, no install, no dependencies needed.

## Available Certifications

| Code | Name |
|------|------|
| COF-C02 | SnowPro Core (retiring May 2026) |
| COF-C03 | SnowPro Core |
| ARA-C01 | SnowPro Advanced: Architect |
| SEA-C01 | SnowPro Advanced: Security Engineer |
| DSA-C03 | SnowPro Advanced: Data Scientist |
